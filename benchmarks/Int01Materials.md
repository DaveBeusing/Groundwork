# INT-01 near and orbit material measurement

Run on the designated #88 Windows x64 reference machine with the same driver and power settings throughout. The default records five pairs and 2,000 measured frames per variant per phase at 1920×1080. Each pair uses a fresh test process and alternates which variant runs first. Both phases receive 32 warm-up frames per variant.

```powershell
./benchmarks/Measure-Int01Materials.ps1 -Adapter Hardware -MachineLabel reference-candidate -OutputDirectory ./artifacts/int01-reference
```

For a harness check, use `-Pairs 1 -Frames 16 -MachineLabel local-workstation`. Use `-Adapter Warp` and a new output directory for a separate software run. The hardware qualification selects NVIDIA. Use `-DebugLayer` with Graphics Tools for a short diagnostic run. The full performance recipe leaves Debug Layer and DRED disabled to avoid measuring validation overhead and filling the bounded message queue. Each report records the diagnostic mode. The script captures the source commit and checkout cleanliness, CPU, memory, Windows, SDK, and the actual DXGI adapter and driver. It preserves locked restore and Release build logs, per-pair raw timings and TRX files, and per-run and pooled nearest-rank percentiles. The harness rejects a missing phase or a change in the scene hash, shader digests, adapter, or runtime between runs.

The near phase uses the native INT-01 fixture's voxel floor generator, with the rock/ore boundary centered at canonical X=0. It follows a repeated 32-step camera path with fixed sunlight and two shadow cascades. The orbit phase uses the authored uncarved orbit proxy and its mapped rock material from the orbit fixture, with a repeated 32-step pan and fixed unshadowed sunlight. Both variants use identical packed geometry, including the appearance vertex stride, along with the same views, camera path, lighting, and viewport. The disabled route selects no material set and draws through the existing terrain lighting path. The enabled route binds the authored palette and native maps and executes the compiled triplanar PBR path. An untimed pixel probe checks that the two routes change color while preserving depth. The scene digest includes actual packed geometry, numeric palette values, texture IDs and camera and light inputs. This comparison holds geometry packing fixed.

CPU record time spans the prepared-plan through recorded-plan hooks. The direct queue timestamp brackets the terrain pass. Turn time spans the offscreen submit and its retirement wait, including its fixed color/depth copy. Each device reuses one 1080p render target and readback buffer. Managed pixels are produced once per variant per phase for the untimed probe. Backing observations report live map descriptors, native residency and material constants, aligned staging and combined high-water, in-flight retained bytes and released bytes, plus setup copy payload. Steady-state draws perform zero texture uploads. No replacement occurs in the benchmark, so retiring predecessor bytes remain zero. The native replacement fixture separately checks predecessor retirement.

The workload measures steady-state near and orbit terrain draws offscreen. The window fixtures cover Present, paused redraw, appearance handoff, and protected terrain ordering. This benchmark provides reproducible scene and shader comparisons, while reference hardware, the agreed mixed workload and any acceptance ceilings still need their own qualification.
