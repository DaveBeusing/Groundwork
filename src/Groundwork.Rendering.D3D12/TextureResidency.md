# D3D12 texture residency

Attach a `D3D12TextureHandoff` to a volume renderer before starting it. Publish the world, renderer epoch, view, terrain revision, coverage generation, and complete appearance target set. Each material input has its own sequence. Retain the exact target when changing an unrelated palette slot.

Reserve source, scratch, cooked payload, copy staging, aligned native allocation, and one descriptor before starting a worker. Cook or read and validate the asset with the portable `TextureCooker` on the producer side within that reservation. Transfer the immutable result after the worker releases its source and scratch, or settle the ticket after cancellation and worker exit. Request credit includes the candidate while the prior binding still owns its native credit.

Use `TryRequest` for a static level-zero binding. For distance-driven residency, pass a fine mip index, a coarser mip index, a promotion distance and a greater demotion distance in `D3D12TextureMipPolicy`. Pass separate reservation ceilings for the fine and coarse resource. The first request selects coarse. Once the first mip is resident, near demand can select fine. View distances between the two thresholds preserve the preceding demand. Each accepted ticket authorizes one worker; coalesced requests authorize none. A missing or invalid asset, or rejected native preparation, ends retries in the same demand band. Quota denial leaves the next request to the caller after capacity changes.

The renderer preflights the selected cooked mip as the sole initialized level of its own committed native texture. It checks the format, dimensions, source range, padded copy footprint and aligned allocation before native creation. On adapters that require BC1 level-zero alignment, the renderer searches toward finer legal mips within the candidate's issued credit. `TryReadResidency` gives the requested mip, the sampleable cooked mip if present, and its aligned backing bytes. A replacement gets its own descriptor version unless its physical tier is already resident. When a tier change exceeds the overlap budget, the resident tier stays drawable. If there is no valid resident tier, the legacy fallback stays drawable while credit is unavailable.

A bounded queue turn can submit one texture copy of at most 2 MiB including the footprint. Protected volume staging and presentation receive priority. On compatible spare turns shared with WP16, the owner alternates eligible prop work and texture copies. When both texture classes remain ready, at most two first-use copies run before granting a replacement turn. The oldest request in each class goes first. The owner polls assigned copy retirement independently of scene traffic, settles staging after the copy fence, and installs a current binding at the next eligible render boundary. A successful installation can redraw authorized terrain while paused.

The reference route samples the lowest declared BaseColor target from the current cut, using the installed tier and cooked sRGB interpretation. An unavailable target uses existing terrain color. Data and Normal targets have distinct validation and remain available for later shader consumers. The reference sampling coordinates are local to the existing terrain vertex route. INT-01 owns canonical material selection and projection. The shader-visible heap retains separate slots for the material and shadow bindings.

`ReadTextureDiagnostics()` reports actual resident and pending native bytes, staging bytes, combined native high-water and copy traffic. Camera and scene submissions upload zero texture bytes. A failed signal retains possible native references and their credits until existing queue custody settles or device removal is confirmed.

With resource snapshots enabled, the same Direct Queue ledger reports texture and texture staging separately. A copy updates the submitted fence and its own copy fence. Frame sequences, draw and Present fences, and pass observations still describe scene submissions. The terrain pass counts the texture backing when it records a draw that samples the binding.
